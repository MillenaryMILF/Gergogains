Connect once

This page needs permission to write to your repository. That comes from a GitHub token you create yourself and paste here. It is stored only in this browser and is never part of the website.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: anything, e.g. site editor
  3. Expiration: 90 days. Shorter is safer; you just repeat this when it lapses.
  4. Repository access: Only select repositories → Gergogains
  5. Permissions: Repository permissions → Contents → Read and write. Nothing else.
  6. Generate, copy, paste below.
Treat this token like a password.
It can write to this repository, so do not paste it on a shared or public computer, and do not put it in a screenshot. Scoped as above it can do nothing else — it cannot touch your other repositories, your account settings or your billing. If it ever leaks, delete it on the GitHub tokens page and the access is gone immediately.
